# Politique de sécurité

Si vous identifiez une vulnérabilité, ne publiez pas immédiatement de détail exploitable dans une Issue publique.

Pour effectuer un signalement privé, contactez le mainteneur via son profil GitHub : https://github.com/Drentarra.

Indiquez une description du problème, les versions concernées et les étapes de reproduction. Le mainteneur évaluera le signalement et coordonnera une correction avant toute divulgation publique.

DOFUSIC - CONSTRUCTION PORTABLE WINDOWS X64
============================================================

1. Sur un PC Windows x64 avec Internet, lance BUILD_PORTABLE.bat.
2. Le builder prépare un environnement isolé dans .portable-build.
3. Il lance les tests, prépare l'OCR, construit Dofusic.exe et l'auto-teste.
4. Le fichier à partager est :

   Release\Dofusic_*_LOCAL_WINDOWS_X64_AVEC_MUSIQUES.zip

UTILISATEUR FINAL
-----------------
Extraire le ZIP dans un dossier puis lancer Dofusic.exe.
Aucun Python système, pip, droit administrateur ou installateur Dofusic n'est requis.

Le ZIP contient :
- Dofusic.exe
- Data\
- Un dossier Musiques/ contenant les fichiers .opus suivis dans le dépôt GitHub,
  et aucun fichier de diagnostic. Le build refuse un dossier source sans OPUS.

Les pistes sont directement lisibles depuis Dofusic/Musiques/.
Vous pouvez ajouter ou remplacer des pistes après extraction, y compris dans des sous-dossiers.
Si le dossier de l’application est protege en ecriture, les reglages sont conserves
dans %LOCALAPPDATA%\Dofusic\ et le dossier portable n’est pas modifie.

PROFIL PORTABLE
---------
- Bibliothèque musicale exclusivement locale.
- Reconnaissance OCR PP-OCRv6 Small par ONNX Runtime CPU.
- Capture par défaut à 10 FPS, interface rafraîchie toutes les 80 ms et OCR adaptatif.
- Visualiseur FFT et normalisation configurables dans Paramètres.
- Aucune plateforme musicale ou compte extérieur requis.

Le programme fonctionne hors ligne : Internet est seulement requis pour les dépendances
et les modèles OCR au moment de la compilation, et pas pour lire les musiques locales.

AUDIO / STOCKAGE
----------------
- Musiques : lecture et file d'attente de fichiers locaux.
- Local : formats audio courants acceptés via FFmpeg.
- Format conseillé : Opus 64 kb/s.

Aucun fichier de log ou de rapport de plantage n'est créé par Dofusic.
Les préférences locales sont conservées dans un fichier de configuration.
